# Glossary

- **Work Block** — a continuous stretch of focused work of configurable length. Starts when the user picks a preset, presses Continue, or Auto-start fires. Ends by expiring, after which a Break begins immediately.
- **Presence** — the state in which the desktop session is unlocked, so the user is at the computer. Presence needs no keyboard or mouse proof and no focused window. A Screen lock ends it.
- **Presence window** — the continuous Presence duration that triggers Auto-start. Default 5 minutes, user-configurable from 1 to 60. A Screen lock resets it.
- **Auto-start** — the automatic start of a Work Block of the Default Preset when the Presence window elapses in the Idle phase inside Working hours. It also starts from Disabled, but only after a Screen lock has re-armed it. It never fires during a Work Block, a Break, or the finished-break wait, and never outside Working hours.
- **Screen lock** — the locked session or the active screen saver. It ends Presence, pauses a running Work Block, and re-arms Auto-start after a manual Disable.
- **Paused Work Block** — a Work Block whose remaining time and Desk Reminder countdown freeze while the screen is locked. It resumes from the frozen time on unlock. A Break is never paused.
- **Break** — the enforced rest period that begins the instant a Work Block expires. Shown as a fullscreen overlay. Itself of configurable length. The user may take *longer* than the Break length (the overlay simply waits); they may not take less without Skipping.
- **Preset** — a Work/Break minute pair labeled by its own minutes ("W/B"), with an *optional* explicit Large-Break length. Six fixed slots: three **Built-in Presets** (50/10, 25/5, 45/15 — always present, never deletable) and three **User Presets** (freely creatable, replaced, deleted). The total never exceeds six.
- **Default Preset** — the single Preset marked as the star; selectable by the user among all six slots, not tied to position. It is the Preset started by Enable and by Auto-start.
- **Desk Reminder** — an auxiliary countdown (default 30 min, user-configurable, with an on/off toggle) that runs **only during a Work Block**, resetting at every Work Block start and on dismissing the Desk Overlay. Its countdown freezes with a Paused Work Block. Independent of the Work/Break machine: it never starts, extends, or enforces anything — it only raises the Desk Overlay.
- **Desk Overlay** — a fullscreen prompt telling the user to change their standing-desk height by doing the reverse of what they are currently doing (no sit/stand distinction is modeled or displayed). Acknowledged with a single button; acknowledging resets the Desk Reminder. A due Break always takes precedence over a pending Desk Overlay.
- **Large Break** — the extended Break that arrives on schedule: after the Cycle allows three normal Breaks, the fourth Work Block's Break is large. Its length is either the Preset's explicit Large-Break value, or — if unset — derived from the automatic rule: normal Break ≤6 min → 20 min; 7–12 min → 30 min; ≥13 min → 40 min.
- **Cycle** — the recurring count of Work Blocks. Every Work Block advances it, whether its Break ran fully or was Skipped. Default Cycle length 4 (three normal Breaks, then one Large Break); configurable.
- **Continue button** — the button on the Break overlay that ends the Break and starts a fresh Work Block. It is **disabled and grayed out for the entire Break duration**; it enables exactly when the Break timer finishes. From then on the overlay waits indefinitely.
- **Skip (break)** — an explicit, separate control, always available during a Break, that ends the Break immediately and starts a fresh Work Block. Protected by a confirmation click so it cannot be triggered accidentally. Distinct from the disabled Continue button. Does not alter the Cycle.
- **Delay Break** — a button shown when a Work Block expires (with the overlay up) that postpones the Break by 5 minutes and resumes work immediately. Repeatable — each click adds 5 more minutes.
- **Start Break Now** — a popup action available while a Work Block is running (e.g. during a Delay Break) that ends the work immediately and starts the due Break.
- **Disabled for now (Meeting mode)** — a manual state toggled from the panel popup. While disabled, all timing and overlay behavior is suspended. A Screen lock re-arms Auto-start; sustained Presence after the next unlock starts the **Default Preset**. Re-enabling manually also starts a fresh Work Block of the **Default Preset**.
- **Panel widget** — a Plasma 6 panel icon showing timer state (idle / remaining time while running). Left-click opens a popup: Presets (click to start immediately) and Disable for now.
- **Overlay** — the fullscreen overlay surface shown during a Break, rendered at the Wayland layer-shell Overlay layer so it sits above all windows including fullscreen apps (ADR-0001 as amended by ADR-0002). Displays rest-time messaging and the remaining Break time, the Continue button, and Skip.
- **Media Pause** — at the instant a Break starts, all playing MPRIS media (music, videos) is paused. Playback is never resumed automatically.
- **Chime** — the bundled, soft piano arpeggio (~2–3 s, gentle decay) played once when a Break begins and when the Desk Overlay appears. Replaces the freedesktop alarm sample.
- **Working hours** — the fixed daily span, 9:00 to 17:00 local time, every day, during which Auto-start may fire. The gate applies at the instant of the automatic start: Presence accrued outside Working hours still counts toward the Presence window, and a Work Block started inside Working hours is never cut short by their end. Manual starts are never gated.
- **Wall-clock deadline** — the persisted absolute end-time of the current phase. All timers derive their remaining time from it, so logout, reboot, or plasmashell restart never loses or stretches a running phase — except a Paused Work Block, whose deadline shifts by the paused duration by design (ADR-0003). A Break keeps its wall-clock deadline.
